## 🔭 Current Projects

- 🛰️ **[Agent-RS](https://github.com/lryoooow/Agent-RS)** — An LLM-powered platform for remote sensing image processing. Describe the task in natural language, and the agent does the rest.
  - **Smart Workbench**: natural-language tasks, place-name search, map-based area selection, layer management and result download.
  - **Satellite Imagery Center**: search Sentinel-2 / Landsat by region, date and cloud cover, with preview, download and import.
  - **SAM3 Segmentation**: concept-prompted multi-target extraction with instance outlines, bounding boxes and statistics.
  - **RS Toolbox**: quality checks, spectral indices, water / cloud-shadow masks, object detection, clipping and reprojection.
  - **Knowledge & Report Center**: knowledge retrieval, knowledge-graph views and one-click Word report generation.
  - **Orbit Awareness**: real-time satellite positions and orbits on a 3D globe.
